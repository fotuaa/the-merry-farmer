* Лабораторная 5 (в процессе сдачи)
* Лабораторная 5 Вариант 4. Погодные условия и климат (struct Weather) \ 
Опишите структуру погоды в структуре игрового мира (enum WeatherType: Ясно, Ливень, Туман, Ураган; температура; сила ветра). Погода меняется случайно при наступлении нового дня или при переходе на новую локацию. В «Ливень» каждый шаг в походе тратит в 2 раза больше выносливости, а в «Ураган» при попытке сделать шаг есть шанс 20%, что героя сдует на соседнюю клетку. 

* Лабораторная 4 Вариант 6. Я блинмб Бетмен \
Ночной лес. Вся карта изначально залита символом ?. При нажатии специальной клавиши (например, R), герой "кричит", и все препятствия в радиусе 5-7 клеток раскрывают себя (отрисовываются нормально) на 2-3 следующих шага, после чего снова скрываются во тьме.

* Лабораторная 3 Вариант 5. Анализатор логов \
В input.txt записан системный журнал событий, где каждая строка начинается с тега важности: [INFO], [WARN] или [ERROR] (например, [ERROR] Здоровье игрока отрицательное, но он жив). Программа должна подсчитать общую статистику по каждому из трёх типов сообщений, а в output.txt выписать только строки с предупреждениями ([WARN]) и ошибками ([ERROR]), предварительно удалив сам тег из начала строки и добавив номер строки из исходного файла. 

* Лабораторная 2 Вариант 5. Очистка от мусора \
Запросить у пользователя ID предмета. Пройтись по массиву и заменить все вхождения этого ID на 0. Вывести на экран, сколько слотов было очищено.
